Scrum Project Foundation (`project_scrum`) adds Agile teams, Sprints and historical
scope evidence to Odoo 19 Community Project. It extends native Project tasks through
[Agile Project Core](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/main/addons/project_agile),
its sole direct dependency. Both addons are LGPL-3; native `project` is a transitive
dependency.

Use ordinary Odoo lists, forms and actions to plan work, start a Sprint, record scope
changes and close unfinished work explicitly. One Sprint may be active per Project
and Agile team; different teams can have active Sprints in the same Project.
Analytics, the interactive planning board and document integrations are optional
separate addons.
