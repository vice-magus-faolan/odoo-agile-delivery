1. As a Project administrator with page editor access, open **Project >
   Projects**, open the Agile Project form and its **Settings** tab.
2. Under **Agile Documentation**, choose **Create Documentation Root**. This
   creates and opens an active content page assigned to this Project and its
   company. Edit its content with the native Document Page editor.
3. To designate an existing page instead, select **Agile Documentation Root**
   and save. The page must be active content already assigned to the same
   Project, with either no company or the Project company; categories, archived
   pages and pages from other Projects are rejected.
4. Choose the **Documentation** stat button to return to the page.
5. To replace the root, choose **Clear Documentation Root** and confirm, then
   select or create its replacement. Clearing removes only the designation;
   the old page, its Project relation and hierarchy remain intact.

If opening fails after a page was archived or changed to a category, restore an
appropriate active content page or clear and replace the designation. Actual
page deletion is different from clearing: native deletion removes page history
and clears the optional root link.
