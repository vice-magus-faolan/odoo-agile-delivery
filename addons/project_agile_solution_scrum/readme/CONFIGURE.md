Install **Agile Solution Scrum Context** (`project_agile_solution_scrum`). Follow
[Solution configuration](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/main/addons/project_agile_solution#configuration)
and [Scrum configuration](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/main/addons/project_scrum#configuration)
for the same Agile Project.

Before linking requirements or starting a Sprint, use a Project Administrator
(Project Manager) account with write access to that Project and its affected
records. Project users can read permitted Sprint history and exact context;
company and referenced-record access still apply. The bridge requires no separate
capture switch and grants no additional access.
