1. As a Project administrator with page editor access, open **Project > Tasks >
   Sprints** and a Draft or Active Sprint.
2. On **Retrospective**, choose **Create Retrospective**. The action creates a
   content page under **Sprint Retrospective Template**, copies its template
   text, assigns the Sprint Project and company, and opens the native editor.
   Fill in the goal, outcome, what went well, what did not, actions and owners.
3. Alternatively, select an existing **Retrospective** page and save. It must be
   active content belonging to the same Project and exactly the Sprint company.
4. Use the header **Retrospective** button to reopen the page. Before closing
   the Sprint, choose **Clear Retrospective** if you need a different link.
   Clearing neither deletes nor reparents the old page.

Closed Sprints cannot change or clear this link, but the linked page remains a
native editable Document Page for authorized editors; it is not a frozen copy.
If creation reports that the template is unavailable, have the Document Page
administrator check that **Sprint Retrospective Template** exists, is active and
is a category you can read. If opening fails, check page access, active content
status and Project/company assignment. Deleting the page is not the same as
clearing its designation: native deletion removes its page history.
