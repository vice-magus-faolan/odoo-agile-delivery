# Scrum Document Page

Optional Odoo 19 Community bridge for Sprint retrospective pages on OCA Document Page.
Depends on `project_scrum` and `document_page_project`; the base Scrum addon remains
independent of Document Page.

See [the adoption decision](../../docs/adrs/006-knowledge-relationship-model.md) and
[the existing fixture notes](../../docs/research/odoo-19-oca-document-page-fixture.md)
for compatibility and verification scope. The repository's canonical `./scripts/verify`
is the CI gate; this optional OCA fixture is not added as a parallel hosted lifecycle
path.
