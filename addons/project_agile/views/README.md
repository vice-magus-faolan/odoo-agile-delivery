# View boundary

`project_agile` uses inherited Odoo Project and Task views only. It adds no custom
JavaScript or OWL component.

The module adds opt-in project configuration, conditional Agile task fields,
manager-only item-type configuration, Product Backlog navigation, and Agile search
filters/grouping. Backlog ordering uses the existing list handle widget against the
explicit `agile_backlog_sequence` field.
