View repository, branch, commit, pull-request and check observations alongside
Odoo 19 Community Projects and tasks. This addon depends on `project_agile`;
install `project_agile_git_github` to receive signed GitHub deliveries.

Repositories belong to one Agile-enabled Project and inherit its company.
Project users read facts within their Project visibility and allowed companies;
Project administrators configure repositories and inspect deliveries. Task buttons
show facts associated with explicit Agile keys, such as `ENG-142`.

Git facts report provider observations. Continue to review and complete tasks
through your Project workflow; stage application belongs to the separately
configured `project_agile_git_automation` addon.
