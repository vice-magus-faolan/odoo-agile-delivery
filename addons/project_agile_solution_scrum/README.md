# Agile Solution Scrum Context

Optional Odoo 19 Community bridge depending on `project_agile_solution` and
`project_scrum`. Captures frozen exact requirement context at native Sprint scope
events; it does not turn a scope event or Task completion into acceptance.

See [Task traceability](../../docs/implementation/m8-task-traceability.md) for the
existing capture and retention contract. Run the repository's `./scripts/verify` for
native discovery, isolated bridge installation and actual scope-event races.
