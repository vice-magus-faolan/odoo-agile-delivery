No analytics settings are required. Follow the
[Scrum setup guide](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/19.0/addons/project_scrum#configuration)
to configure an Agile Project and its Sprints. Sprint setup and lifecycle actions
require **Administrator** under **Project** in user access rights, called Project
administrator below. Project users can read reports for accessible Projects and
available companies; reports and timeline points cannot be edited manually.
