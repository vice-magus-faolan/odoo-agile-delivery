Scrum Project Foundation (`project_scrum`) adds Agile teams, Sprints and scope
history to Odoo 19 Community Project. It builds on
[Agile Project Core](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/main/addons/project_agile).

Plan work, start a Sprint, track scope changes and decide where unfinished work
goes at closing. One Sprint may be active per Project and team; different teams
can have active Sprints in the same Project.
