Agile Project Core (`project_agile`) adds opt-in Agile work items to Odoo 19
Community Project. Work items remain native Project tasks, with subtasks and
dependencies, configurable item types, stable keys, Fibonacci story points,
acceptance criteria and an ordered backlog.

Enable Agile separately on each Project. For teams and Sprint planning, add
[Scrum Project Foundation](https://github.com/vice-magus-faolan/odoo-agile-delivery/tree/19.0/addons/project_scrum).
